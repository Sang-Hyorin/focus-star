# Changelog

## 1.0.0

- Initial public Windows and macOS source release.
- Local foreground-app tracking, configurable idle rules and star dashboard.
- Overlapping interval deduplication, per-device archives and local recovery buffers.
- Generic default settings, reproducible builds and synthetic regression tests.
- Universal macOS build and Windows .NET Framework build.

Release versions describe the combined distribution. Internal Windows and Mac
application version metadata may differ.
